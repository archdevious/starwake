# Starwake

A slow-light space exploration game for desktop browsers. Humanity, the real nearby stars, no faster-than-light travel.

Play: https://archdevious.github.io/starwake/

Build: `python3 build.py` combines `src/` into `index.html`. `gen_stars.py` regenerates `src/stars_data.js` from the HYG star catalogue.
